# workManage-WebFront
> [!NOTE]
> ### 概要
課題管理システムのフロントエンド、バックエンドにjavalin製のAPIを採用

> [!NOTE]
> ### 機能 
- PWAによるWEBアプリ化
- キャッシュ機能によるオフライン時表示(
データ更新はオンライン)
- 完了・未完了の個別表示・切り替え
- カレンダーによる日付別表示
  
> [!NOTE]
> ### バージョン
<ユーザー>    利用者の体感に影響を与える内容  
<サイレント>  内部のリファクタリングや改善
- ### v2.0
  -<ユーザー>カレンダー機能の追加による日付単位での課題の表示を追加
  -<サイレント>バックエンドのjavalin製独自API化による応答速度の向上(5〜10倍)
  -<サイレント>内部ロジックの整理によるメンテナンス性の向上
- ### v1.5
  - <ユーザー>各課題の残り時間を計算し24時間未満なら赤文字＋分単位で表記 24時間以上は日単位で表示するように調整
  - <サイレント>CSSを整理
